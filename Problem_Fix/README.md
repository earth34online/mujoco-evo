## 接触、放置与纠正数据

- 方块、筷子和抽屉使用真实物理接触和稳定终点。抓取要求双指证据，安全控制追踪实际执行和保护拦截。筷子及抽屉分别跟踪夹持、运输掉落、受支撑放置和开爪。
- 抽屉初期失败集中在错误或过早的夹爪转换。四个 A/B 救回场景第一次动作分歧在接近把手阶段，分歧前机械臂状态和请求位姿一致。位姿动作继续来自模型，夹爪执行只聚合同一时刻的预测。
- 存在已入区但持续下探、尚未入区便下探，以及开屉后取物时撞上相邻把手的轨迹。真实失败视频和逐步动作用于辨别模型预测、控制拦截与物体状态，评分维持原严格标准。
- 失败轨迹可用于离线纠正采集。二值开爪值 `1.0` 可进入释放掉落筛选，区外落点重算采用数值坐标。对真实回放中已稳定且仍无法开爪的状态，验证后采集抬离接收面再释放。失败策略前缀仅作为历史。已验证的发布模型提升来自执行端改动，权重和数据未因此更新。
- 数据写入验证质量、观测与动作维度、真实回合边界、环境资产哈希和接触契约。离线校验与物理回放用于定位，严格闭环用于验收。

## 2026-11-18 方块与下层抽屉根因修复

发布权重、归一化、训练数据和动作头保持原样。本轮没有训练、采集或部署专家动作。

方块两个失败在腕高约 189 mm、XY 偏离约 20 mm 时闭爪，未接触物体便空手搬运。接近阶段尚未触发原精细重规划条件，连续执行旧动作块导致过早闭爪。将执行块长度改为 1，保留滤波、物理和评分，同一 30 场景完整回归为 30/30。默认仅针对发布权重哈希应用；显式 `--horizon` 和其他权重保持原行为。服务端推荐值和客户端使用同一个发布设置函数。

抽屉四个失败全部为下层目标，原下层为 5/9，其余三个目标共 21/21。四例都选对并打开，却没有夹起物体。失败前已出现位姿执行跟踪偏差，随后旋转状态越界，最终在相邻把手或下层衬板处持续被保护拦截。取消旋转归一化裁剪的诊断仍失败，未采用；位姿动作聚合只能救回 3/4，也未纳入默认。

在 seed 1536547409 第 140 步精确重放（状态差 0），固定当前关节目标后，2 ms 积分仍产生约 0.6 rad/s 的关节 1/3 振荡，力矩持续达到 87 Nm。保持同一个初态、模型和目标，仅改为 1 ms 或 0.5 ms 积分后，振荡收敛到约 1e-7 rad/s。IK 调用前后检查的 qpos、qvel、warmstart、ctrl 和外力均不变，未据此误改 IK。

MuJoCo 官方指南说明，执行器力限饱和时不再提供隐式阻尼，减小积分步长是数值稳定性的处理方法之一。这里采用积分细分，不调整质量、摩擦、力限、场景或成功判分。[MuJoCo numerical stability](https://mujoco.readthedocs.io/en/stable/modeling.html)
