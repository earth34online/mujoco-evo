## 训练、推理与评估契约

| 故障 | 处理 |
|---|---|
| 相同 checkpoint 名称指向旧服务 | 客户端核对实际载入的路径和更新步数；发布模型额外核对哈希，报告保存 checkpoint 身份。 |
| 训练和推理的相机、状态与动作语义不齐 | 使用无损 RGB，统一历史时序、前视图、状态归一化和任务动作掩码。原抽屉数据 10,524 个时序位置的有效历史索引与掩码匹配。 |
| Parquet 物理时间与视频、样本跨回合、尾部填充产生监督偏差 | 以采集时物理时钟对齐。历史留在本回合内，补齐的动作行不计入监督。 |
| 训练中的二分类、推理夹爪符号和阶段时机不稳定 | 抽屉夹爪二分类保持独立，原始 52,312 行归一化标签检查一致。执行端在同一控制时刻对齐最多四份已出现的预测，按分数通过原开合滤波。没有仿真真值输入。 |
| BF16 动态路径、冻结特征与失败恢复 | 长训练使用有持久优化器的正式入口；固定冻结视觉特征模式，检查 NaN/Inf，记录实际后端。处理过的中断写 `step_interrupted`，达到预算写 `step_final`。CUDA 上下文错误仍需从已保存的完整点恢复。 |

## 接触、放置与纠正数据

- 方块、筷子和抽屉使用真实物理接触和稳定终点。抓取要求双指证据，安全控制追踪实际执行和保护拦截。筷子及抽屉分别跟踪夹持、运输掉落、受支撑放置和开爪。
- 抽屉初期失败集中在错误或过早的夹爪转换。四个 A/B 救回场景第一次动作分歧在接近把手阶段，分歧前机械臂状态和请求位姿一致。位姿动作继续来自模型，夹爪执行只聚合同一时刻的预测。
- 存在已入区但持续下探、尚未入区便下探，以及开屉后取物时撞上相邻把手的轨迹。真实失败视频和逐步动作用于辨别模型预测、控制拦截与物体状态，评分维持原严格标准。
- 失败轨迹可用于离线纠正采集。二值开爪值 `1.0` 可进入释放掉落筛选，区外落点重算采用数值坐标。对真实回放中已稳定且仍无法开爪的状态，验证后采集抬离接收面再释放。失败策略前缀仅作为历史。已验证的发布模型提升来自执行端改动，权重和数据未因此更新。
- 数据写入验证质量、观测与动作维度、真实回合边界、环境资产哈希和接触契约。离线校验与物理回放用于定位，严格闭环用于验收。
